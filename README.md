# openGL_Clasters

Визуализация алгоритма кластеризации точек на C++ с использованием OpenGL.

## О проекте
Учебный проект по компьютерной графике. Программа отображает набор точек и результат их кластеризации в реальном времени. Реализована базовая отрисовка через OpenGL (GLFW + GLAD), сборка через CMake с использованием vcpkg.

## Стек
- C++17
- OpenGL, GLFW, GLAD
- CMake, vcpkg
